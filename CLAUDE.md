# Model usage rules

Goal: stretch the weekly usage limit. Opus costs far more than Sonnet, so use it sparingly.

- Default to Sonnet for everything: reading code, small edits, bug fixes, refactors, running tests, and routine feature work.
- Use Opus only for genuinely heavy coding tasks: large multi-file changes, hard architectural work, or difficult debugging that Sonnet has already failed at.
- Planning and review are always Sonnet, never Opus.
- When delegating to subagents, use Sonnet unless the subtask is a heavy coding task.
- Never run several parallel Opus sessions or subagents at once.
